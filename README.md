# 🐍 10 Days – 10 Python Projects

Welcome to my **10 Days – 10 Python Projects Challenge** 🚀

The goal of this challenge is to build one small Python project every day for 10 consecutive days and strengthen my Python programming fundamentals through hands-on practice.

Instead of only learning Python concepts theoretically, I am applying them by building practical mini projects.

---

## 🎯 Challenge Goals

- Strengthen Python fundamentals
- Practice problem-solving
- Learn by building projects
- Work with Python libraries
- Understand APIs and JSON
- Practice file handling
- Explore GUI development
- Build a consistent GitHub project portfolio
